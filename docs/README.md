# Documentation

This directory contains durable project and architecture documentation that is
broader than a single application folder.

Architecture decision records will live under `docs/architecture/decisions/`
when the initial ADR work is introduced. Development instructions should stay
close to the workflow they explain and be linked from the root README.

Generated reports and temporary notes do not belong here.
